# 🏥 Hospital Record System

A simple **Hospital Record System** built using Python. This beginner-friendly project allows users to add and view basic patient information such as patient name, disease, doctor name, mobile number, and address.

## 📌 Features

* Add patient name
* Add disease name
* Add doctor name
* Add patient mobile number
* Add patient address
* View patient record
* Exit the program
* Simple menu-driven interface

## 🛠️ Technologies Used

* **Python**
* **Dictionary**
* **While Loop**
* **If-elif-else**
* **For Loop**
* **Input/Output**

## ▶️ How to Run

1. Make sure Python is installed on your computer.
2. Download or clone this repository.
3. Open the project folder in VS Code or Command Prompt.
4. Run the following command:

```bash
python hospital_record.py
```
