# Hospital Record System 🏥

## About the Project
The **Hospital Record System** is a beginner-friendly Python project that helps manage basic patient information through a simple menu-driven program.

## Features
- Add Patient Name
- Add Disease Name
- Add Doctor Name
- Add Patient Mobile Number
- Add Patient Address
- View Patient Record
- Update Existing Patient Details
- Validate 10-digit Mobile Numbers
- Exit the System

## Technologies Used
- Python
- Dictionary
- While Loop
- If-elif-else Statements
- User Input and Output

## Learning Outcomes
- Understanding Python dictionaries
- Using loops and conditional statements
- Updating dictionary values
- Validating user input
- Building a menu-driven application
